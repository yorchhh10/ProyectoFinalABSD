# PROYECTO FINAL ADMINISTRACIÓN BASE DE DATOS GIMNASIO📑

Proyecto desarrollado en SQL Server para gestionar la operación de un gimnasio. La base de datos `Gimnasio` registra socios, planes de membresía y pagos, además de entrenadores, especialidades, clases, sesiones y reservas.
